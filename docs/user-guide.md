# 使用说明

> 面向**不需要懂编程**的使用者。照着做即可，不需要安装任何开发工具。

---

## 一、安装

### 第 1 步：把 APK 传到手机

从本项目的 **Releases 页面**下载最新版 APK。

传到手机的方式随你挑：

- **数据线**：手机插电脑 → 把文件拖进手机的「下载」文件夹
- **微信**：发给「文件传输助手」，然后在手机上点开
- **QQ**：发给「我的电脑」，然后在手机上点开

### 第 2 步：在手机上点击安装

点开这个 APK。手机会提示「**未知来源应用**」或「**禁止安装未知应用**」——
这是正常的，因为这个 App 不是从应用商店下载的。

按提示点「**设置**」→ 打开「**允许来自此来源**」→ 返回 → 点「**安装**」。

> 各家手机的提示文字不太一样：
> - 小米 / 红米：「未知来源应用」→ 允许
> - 华为 / 荣耀：「外部来源应用下载」→ 允许
> - OPPO / vivo / 一加：「安装未知应用」→ 允许

### 第 3 步：打开 App

桌面上会出现一个**蓝色圆形、里面是课表网格**的图标。

---

## 二、第一次使用

1. 打开后会看到登录页
2. **学号**填你的学号，**密码**填你的教务系统密码
3. 「记住密码」保持勾选
4. 点「**登录并同步课表**」

等几秒（App 要依次完成：统一身份认证 → 进入教务系统 → 下载课表），
成功后就会直接显示你的课表。

> **勾了「记住密码」之后**：每次打开 App 都自动进主界面，不会再弹登录页；
> 就算登录会话过期，App 也会用记住的密码在后台自动重新登录，你完全无感。
> 只有你自己点「退出登录」，或者改了教务系统密码，才需要重新输入。

> **账号安全**：账号密码只保存在**你自己手机里**，只发给学校自己的认证服务器。
> 这个 App **没有服务器**，所有数据都在本机，不会上传到任何地方。

---

## 三、怎么用

底部有三个标签页：

| 标签 | 作用 |
|---|---|
| **今日** | 今天要上的课，并显示第几教学周。点课程卡片看详情 |
| **周课表** | 左右滑动切周；「本周」高亮。点课程卡片看详情（教师、地点、周次、班级等） |
| **设置** | 学期、开学日期、上课提醒、自动更新、外观 |

常用设置：

- **开学日期**：点「选日期」选**开学第一周的周一**，App 据此推算今天是第几教学周
- **自动选择学期**（默认开启）：按日期自动切到当前学期，不用每学期手动改
- **上课提醒**：开启后会提前提醒，提前时间可选 5～60 分钟
- **外观**：六种主题色、跟随系统 / 浅色 / 深色、可选自己的照片当背景

## 四、⚠️ 两个必须注意的坑

### 坑 1：开代理 / VPN 会连不上学校

学校教务系统的域名是**公网地址**，校外和手机流量都能直接访问，**不需要连学校 VPN**。
但代理软件的「TUN 模式 / 全局模式」会把学校域名**劫持到虚拟网段**，导致连不上。

**症状**：提示「无法连接教务系统」。

**处理**：

- **最简单**：用 App 时把代理软件退出（或关掉 TUN / 全局模式）
- **不想关**：在代理软件里把学校域名加到「直连（DIRECT）」规则

### 坑 2：显示的是「离线缓存」

课表缓存在本机，**没网也能看**。如果状态显示「离线缓存」，说明这次没能联网同步，
看到的是上次的数据——等有网了在课表页下拉刷新即可。

## 五、常见问题

**Q：登录后一直转圈 / 提示「登录已过期」**
教务系统的登录会话由**学校服务器**决定有效期，到期后需要重新登录。
在登录页勾上「**记住密码**」，会话过期时 App 会自动重新登录，你就不会再被打断。

**Q：提醒不响**
国产手机的省电策略会拦截后台提醒。到「设置 → 上课提醒」页，
按里面的品牌指引把 App 加入后台白名单（允许自启动、关闭电池优化）。
那页还有一个「提醒自检（60 秒）」按钮，可以当场验证后台提醒是否正常。

**Q：课表和教务系统上不一样**
在课表页下拉刷新一次。如果还是不对，可能是教务系统刚调课，
或者学期选错了——到「设置 → 当前学期」确认一下。

**Q：想换主题色 / 换背景图**
「设置 → 个性化」。主题色会联动顶栏、按钮、卡片等所有地方。

## 六、自己重新打包

如果你改过代码，或想在自己的电脑上重新编译：

```bash
./gradlew assembleDebug          # Windows 用 gradlew.bat assembleDebug
```

产物在 `app/build/outputs/apk/debug/app-debug.apk`。

需要 **JDK 17+** 与 **Android SDK（platform 36）**；Gradle 版本由 wrapper 锁定，不用手动装。
